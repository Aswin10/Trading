# Pine Scripts

A collection of Pine Script indicators, strategies, and libraries for TradingView.

## Structure

```
indicators/   - Custom indicators and overlays
strategies/   - Trading strategies with entry/exit logic
libraries/    - Reusable Pine Script libraries
```

## Usage

1. Copy the contents of any `.pine` file
2. Open TradingView → Pine Editor
3. Paste and add to your chart
